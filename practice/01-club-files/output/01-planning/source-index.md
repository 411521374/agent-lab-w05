# Source Index

| Source file | Type | Key content | Handling |
|---|---|---|---|
| `announcement.txt` | Announcement draft | Bring a notebook; time and location undecided. | Keep as draft. Same content as `announcement_copy.txt`. |
| `announcement_copy.txt` | Announcement duplicate | Same content as `announcement.txt`. | Preserve and flag as duplicate-looking copy. |
| `budget_draft.txt` | Budget note | Paper budget is 100 imaginary units and not approved. | Keep as unapproved estimate. |
| `equipment_list.txt` | Equipment list | Markers: 4; paper packs: 2. | Keep. Same content as `equipment_backup.txt`. |
| `equipment_backup.txt` | Equipment backup | Markers: 4; paper packs: 2. | Preserve and flag as duplicate-looking backup. |
| `feedback_questions.txt` | Review prompt | Was the task clear? What would change? | Use for review checklist. |
| `meeting_notes.txt` | Meeting note | Decide indoor versus outdoor activities next meeting. | Use for next agenda and decision log. |
| `next_steps.txt` | Planning instruction | Compare both proposals; neither is approved. | Use as decision rule. |
| `poster_text.txt` | Poster draft | Take a short creative break. | Keep as draft copy. |
| `proposal_final.txt` | Proposal draft | Outdoor activity, 30 minutes; not final. | Keep as draft option. |
| `proposal_final2.txt` | Proposal draft | Indoor activity, 20 minutes; still under discussion. | Keep as draft option. |
| `rain_plan.txt` | Contingency note | If raining, discuss an indoor alternative before deciding. | Use as risk/contingency note. |

## Duplicate-Looking Files

| Files | Reason | Action |
|---|---|---|
| `announcement.txt`, `announcement_copy.txt` | Text content matches. | Preserve both; use one announcement draft in communication outputs. |
| `equipment_list.txt`, `equipment_backup.txt` | Text content matches. | Preserve both; use one equipment summary in planning outputs. |

## Non-Decisions

- Do not treat `proposal_final2.txt` as approved only because of its filename.
- Do not infer a time, location, owner, or budget approval from missing data.
